# 🍳 Fridge-to-Recipe AI

An AI-powered web application that takes whatever random ingredients you have in your fridge and transforms them into a structured, delicious, and custom recipe using the Gemini API.

---

## 🚀 Features
* **Smart Recipe Generation**: Inputs raw comma-separated ingredients and parses them into a clean JSON-backed UI.
* **Structured Output**: Displays preparation time, serving sizes, ingredient quantities, step-by-step instructions, and smart ingredient swaps.
* **Lightweight Proxy Architecture**: Secure Node.js/Express backend proxy communicating with the Gemini API.
